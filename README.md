# IT Helpdesk Ticket Analytics

## Project Overview

This project analyzes IT helpdesk support tickets to identify trends in ticket volume, department workload, and priority distribution.

---

## Objectives

• Clean the dataset
• Analyze ticket trends
• Perform SQL analysis
• Build simple business reports

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- SQLite
- Google Sheets

---

## Dataset

The dataset contains:

- Ticket ID
- Ticket Body
- Department
- Priority
- Tags

---

↓

↓

Business Insights

---

## Key Findings

• Technical Support received the highest number of tickets.

• Medium priority tickets were the most common.

• Department-wise analysis identified workload distribution.
